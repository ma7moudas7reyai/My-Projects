# Netflix Front-End Clone  

## 📌 Overview
This project is a front-end clone of the Netflix website built using HTML, CSS, and JavaScript.

It simulates a streaming platform interface including:
- Home page with movie/TV show sections
- Login page with validation
- Registration page with form validation

The project focuses on UI design, layout structuring, and basic client-side validation.

## 📂 Project Structure

- `index.html` → Main homepage
- `login.html` → Sign-in page
- `Register.html` → Sign-up page
- `/css` → Stylesheets
- `/images` → Media files

---

## 🔐 Form Validation

### Login Page:
- Checks for empty email field
- Checks for empty password field
- Redirects to homepage if valid

### Register Page:
- Ensures all fields are filled
- Verifies password confirmation
- Redirects to login page upon success

## ▶️ How to Run

1. Download or clone the repository
2. Open `login.html` or `index.html` in a browser
3. Navigate between pages
